Shulker UI

Makes the Shulker Box UI look nicer

Download Modrinth CurseForge GitHub

Shulker UI is a Minecraft resource pack that improves the appearance of the Shulker Box interface by replacing the default look with a colorful design that matches the specific color of the shulker box being opened. It maintains a vanilla-like aesthetic while providing a visually appealing, themed upgrade to inventory management. Note that this pack requires the OptiGUI mod to function correctly.
