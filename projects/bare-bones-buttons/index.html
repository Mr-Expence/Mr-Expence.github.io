Bare Bones Buttons is a simple Minecraft resource pack that isolates and applies the minimalist, clean button designs from the popular "Bare Bones" resource pack. It affects only the graphical user interface elements—such as the main menu and server list buttons—without altering any other textures in the game, providing a sleek and simplistic look while keeping the rest of the vanilla experience intact.
